# 研究现状 · mean-reversion-barrier-duality

> 类型：Theme / research-status
> 状态：立题（2026-08-02）· 阶段 0（核心假设已数值 + 闭式验证，待真实数据）
> 最近更新：2026-08-02

---

## 1. 一句话结论

低盈亏比 / 高胜率（$R<1$）成为最优，**当且仅当**存在**指向均衡的均值回归型条件漂移**（入场位于偏离处，OU 漂移 $\nu_{\text{cond}}$ 把价格拉回均衡），且在"高频、短持仓、强回归、按时间计成本、下行风险敏感"这类约束下；它与趋势 / 持续过程下的 $R>1$ 最优互为镜像，而非"退而求其次"。

---

## 2. 核心问题

既有 `structural-shaping-alpha` 主题（已冻结）的通道 B 给出：在未知符号的趋势漂移（持续过程）下，非对称塑形的二阶展开

$$E_{\text{gross}}^{\text{trend}} \sim \tfrac{x^2}{3} K_S^3 R(R-1),$$

只在 $R>1$ 时为正，因此结论偏向"高盈亏比 / 低胜率"。本主题补上被遗漏的另一半：

> 当条件过程不是"逃离中心"（趋势 / 持续），而是"回到中心"（均值回归 / 反持续），把近 barrier 放在均衡一侧（止盈近、止损远，$R<1$）时，期望与风险调整收益如何？$R<1$ 在什么条件下严格最优？

---

## 3. 当前结论（阶段 0）

### 3.1 数学结论（OU 模型，已验证）

- **设定**：对数价格服从 OU $dX_t=-\kappa X_t\,dt+\sigma\,dW_t$，均衡 0；入场于偏离处 $x_0=-K_T$（多头，价格低于均衡 $K_T$），止盈于 0（距离 $K_T$）、止损于 $-(K_T+K_S)$（距离 $K_S$），$R=K_T/K_S$。
- **首达胜率 ODE**：$\tfrac{\sigma^2}{2}p''(x)-\kappa x\,p'(x)=0$，$p(-K_T-K_S)=0$，$p(0)=1$（闭式含 erfi，spec §4 给出）。
- **小 κ 展开**（对任意 $K_T,K_S>0$ 都为正，与趋势通道的 $R(R-1)$ 形成对比）：

  $$p_{\text{win}}=\frac{K_S}{K_T+K_S}+\frac{\kappa}{\sigma^2}\frac{K_TK_S(2K_T+K_S)}{3(K_T+K_S)}+O(\kappa^2),$$

  $$E_{\text{gross}}=\frac{\kappa}{\sigma^2}\frac{K_TK_S(2K_T+K_S)}{3}+O(\kappa^2).$$

- **$R^\ast$ 单调性**（数值验证）：固定容器宽度 $L=K_S+K_T$，最优盈亏比 $R^\ast$ 随回归强度 $\kappa$ **单调下降**：

  | 回归强度 $\kappa$ | $R^\ast$（年化 Sharpe） | 对应胜率 | 形态 |
  |---|---|---|---|
  | 0.10（弱回归） | 4.00 | 24% | 高盈亏比 / 低胜率 |
  | 0.50 | 1.10 | 73% | 近似对称 |
  | 1.00 | 0.42 | 96% | **低盈亏比 / 高胜率** |
  | ≥2.0（强回归） | 0.20–0.30 | ≥99% | 极低盈亏比 / 极高胜率 |

  交叉点 $\kappa\approx 0.7\text{–}1.0$（$R^\ast$ 跌破 1）。

### 3.2 Doob 保守律下 $R<1$ 必亏（已验证）

- 鞅过程（$\kappa=0$，BM）下 $E_{\text{gross}}\equiv0$（Doob OST），叠加每笔成本 $2c$ 后**所有 $R$ 都亏**，$R<1$ 不构成生存区。
- 纯反持续增量（AR(1) 增量 $\rho<0$，无指向均衡的漂移）本身**不产生** $R<1$ 正期望（数值验证 $\rho=-0.3$ 仍 $E\approx0$）——必须有**真正的均值回归漂移**（OU 的 $-\kappa x$）。

### 3.3 $R<1$ 严格最优的四条充分条件

至少满足其一，$R<1$ 才从"可行"变为"最优"（详见 spec §7）：

1. **强均值回归**：$\kappa/\sigma^2$ 足够大（年化 Sharpe 口径下 $\kappa\gtrsim1$，临界待真实数据校准）；
2. **按时间计的持有成本**（融资 / 库存 / 机会成本）：奖励快进快出，$R<1$ 持仓时间 $\mathbb{E}[\tau]$ 短；
3. **下行风险 / 回撤敏感目标**：$R<1$ 把损失尾概率压到极低（强 κ 下 $P_{\text{loss}}<1\%$）；
4. **结构性紧止损约束**：止损距离被流动性 / 跳空下限钉住时，只能调近止盈 → 自然落到 $R<1$。

> 注：在"固定容器宽度 + 单笔 Sharpe + 弱回归"下，最优点在 $R\approx1\text{–}1.7$，**不是** $R<1$；$R<1$ 的最优性依赖上述约束。这一边界必须诚实保留。

## 4. 边界与未决项

- **真实数据未验证**：当前全部基于 OU 合成数据 + ODE 数值。真实价格是否在可交易尺度上呈现足够 $\kappa$、且入场偏离可识别，是阶段 1 的核心问题。
- **OU 假设可能过强**：真实均值回归常是 regime-switching、非线性、或有界随机游走；需与 fBm（$H<1/2$）、非线性 SETAR/区间均衡做对照。
- **容量与成本**：$R<1$ 高胜率策略高频、单笔毛利小，对成本 / 滑点极敏感；阶段 1 必须用每合约真实成本，禁用扁平 ATR 成本（继承量化方法护栏）。
- **过拟合风险**：高胜率极易通过"扛单 + 紧止盈"伪造（时间止损失效）。必须用随机方向入场 + 随机持有期双对照，且报告时间退出比例。
- **与既有主题的关系**：这是通道 A（方向 alpha）的镜像，不是新通道；Doob OST 两前提分类不变。

## 4.1 怀疑先验（skeptical prior）：真实市场假设可能不成立

> **核心判断**：阶段 0 只证明了机制在 OU 模型内自洽，**没有**证明真实可交易市场存在让 $R<1$ 对**方向性单品种、散户成本**成为最优的 regime。先验应偏向"不存在 / 不可交易"，阶段 1 是证伪门槛而非确认练习。补充的现实化压力测试（`workbench:.../regime_realism_check.py`、`equilibrium_error_check.py`）揭示三个被合成模型掩盖的问题：

1. **毛利量级被 $L=2$ ATR 容器人为放大**：模型在 $R<1$ 工作点给出单笔 $E_{\text{gross}}\approx0.5\text{–}0.8$ ATR，对应可承受单边成本 $c_{\text{be}}\approx0.23\text{–}0.41$ ATR——这对方向性交易**高得不真实**（流动性好的期货单边约 0.03–0.08 ATR，但那是因为其 edge 本就极小；散户商品 0.1–0.25 ATR）。真实方向性回归的单笔成本后 edge 通常是 0.05–0.2 ATR 量级。模型的高 edge 来自容器宽度归一化与恒定 κ 理想假设，不代表可实现。
2. **$R<1$ 所需 κ 对应极快回归 / 极高胜率（91%–100%）**：这种"秒回均衡"的 regime 在可交易方向尺度上主要属于**做市 / 微结构**（赚 bid-ask，不是方向性 barrier）、**交易所内的价差回复**、或**有界随机游走的极短尺度**——方向性交易者要么进不去（需要做市价差与队列优先权）、要么成本后被吃光。$R<1$ 在经典**统计套利 / 配对交易**里确实成立，但那是**市场中性、均值已知（cointegration）、组合层**，不是本主题的单品种方向性 barrier 设定。
3. **均衡点估计是真正的杀手**：OU 假设均衡 0 已知。实盘里 $\theta$（VWAP/MA/POC）是估计值。压力测试显示：对强 κ（=2），入场偏差被误判到 2×（价格继续向远离均衡方向走，实际偏离 1.5 ATR 而非 0.75 ATR）仍正 edge；但对弱 κ（=1），误判到 2× 直接 $E=-0.77$（接飞刀）。真实趋势日里"均值回归"假设本身失效，宽止损（$K_S$ 大）正是 $R<1$ 的 steamroller 风险。混合坏 regime（$q=10\%$ 随机游走）下数学期望仍正，但**罕见大亏损的回撤分布**会让凯利重仓爆仓——这是典型"picking up pennies in front of a steamroller"。

**因此阶段 1 的立场**：把"方向性单品种 $R<1$ 在真实成本后可交易"作为**待证伪的 null**，通过条件才继续；优先扫描的不是"哪里 $R<1$ 最优"，而是"可交易尺度上 $\kappa$ 分布的上分位有多大、其成本后 edge 与均衡估计误差是否撑得住"。真正可能成立的形态预期收窄到：(a) 市场中性配对 / 篮子统计套利（已知 cointegration）、(b) 事件驱动过度反应后的短窗回复、(c) 有做市能力的微结构尺度——这些与原始"单品种方向性 barrier"问题域已不同，需在阶段 1 后重新界定。

## 6. 关键发现清单

### KF-1 · 鞅过程下 $R<1$ 不存在生存区
- 类型：策略行为 / 假设证伪
- 状态：已证实（Doob OST + 数值）
- 证据：workbench:low-payoff-high-winrate-optimality/objectives_study（BM $\kappa=0$，所有 $R$ 的 $E_{\text{gross}}=0$，扣成本后全亏）
- 影响：任何"低盈亏比高胜率"策略必须以真实均值回归型条件漂移为前提；纯反持续 / 纯噪声不够。
- 日期：2026-08-02

### KF-2 · OU 均值回归下小 κ 闭式胜率与正期望
- 类型：策略行为
- 状态：已证实（ODE 数值与闭式吻合，$\kappa=0.1$ 误差 <0.001）
- 证据：workbench:low-payoff-high-winrate-optimality/verify_ou_analytic
- 影响：给出 $R<1$ 正期望的数学根源——$E_{\text{gross}}\propto\kappa K_TK_S(2K_T+K_S)$，对任意 $R>0$ 为正，与趋势通道 $R(R-1)$ 对偶。
- 日期：2026-08-02

### KF-3 · 最优盈亏比 $R^\ast$ 随回归强度单调下降
- 类型：策略行为
- 状态：已证实（数值，固定 $L=2$；解析单调性待补）
- 证据：workbench:low-payoff-high-winrate-optimality/kappa_threshold_study（$\kappa=0.1\!\to\!5$，$R^\ast$ 从 4.0 降到 0.15）
- 影响：把"趋势用 $R>1$、回归用 $R<1$"统一为一条以 $\kappa$ 为轴的单调律；$\kappa\approx0.7\text{–}1.0$ 为 $R^\ast=1$ 交叉点。
- 日期：2026-08-02

### KF-4 · 纯反持续增量（无回归漂移）不产生 $R<1$ alpha
- 类型：方法论 / 假设证伪
- 状态：已证实（AR(1) 增量 $\rho=-0.3$ 数值，$E\approx0$）
- 证据：workbench:low-payoff-high-winrate-optimality/r_optimality_regimes
- 影响：fBm $H<1/2$ 的反持续性本身不足以支撑 $R<1$ 策略；必须有指向均衡的条件漂移（OU 的 $-\kappa x$）。这把"反持续"与"均值回归"两个常被混淆的概念区分开。
- 日期：2026-08-02

### KF-5 · $R<1$ 严格最优依赖四类约束之一
- 类型：策略行为 / 边界
- 状态：边界待定（四条充分条件已数值验证，精确阈值待真实数据）
- 证据：workbench:low-payoff-high-winrate-optimality/r_optimality_regimes、objectives_study
- 影响：$R<1$ 不是无条件最优；在"固定宽度 + 单笔 Sharpe + 弱回归"下最优在 $R\approx1\text{–}1.7$。研究与宣传时不得把 $R<1$ 普适化。
- 日期：2026-08-02

### KF-6 · 高胜率易被"扛单 + 紧止盈"伪造
- 类型：方法论
- 状态：已识别（阶段 1 必须设对照排除）
- 证据：主题立题分析（无时间止损时 $R<1$ 可靠无限等待做出虚高胜率）
- 影响：实验必须固定时间上限 $T$、报时间退出比例、用随机方向 + 随机持有期双 baseline；禁用"不止损 / 移动扛单"类规则。
- 日期：2026-08-02
