## 0. r1 已确认的基础

r1 确立了以下可作为前提的事实（KF-11/12/17/19/20/21/22）：

1. **成交量是因子方向调节器，不是独立 alpha**（KF-22）：缩量时动量 IC≈+0.2，放量时动量 IC≈−0.4，正常量 IC≈0；
2. **调节作用只在高 s 趋势中成立**（s_pre≥0.10），中 s 层几乎无影响，低 s 层对称但样本不足；
3. **机制**：放量反转漂移 ν 而不改变波动 σ（KF-21），是 s=ν/σ 的外生翻转触发器；
4. **参数**：N=20、H=100、z≥1.5 覆盖全品种；MADEV120≥3% 是最强条件（OOS −1.77%, 82% 负，但衰减且品种集中）；
5. **25/30 个因子被显著调节**，但都是 1h K 线可算的价量因子，且未纳入持仓量、订单流、跨周期信息。

r2 不再重复 r1 的基础验证，聚焦于**r1 无法回答的五个问题**。

## 1. 待验证假设

### H1：缩量端是独立的动量增强信号（优先级最高）

**问题**：r1 发现缩量（z<−0.5）时动量 IC≈+0.2，但只作为放量的对照组出现，未被独立研究。

**假设**：在高 s 上涨趋势中，缩量（z<−0.5）是趋势健康的确认信号，后续动量延续的概率和幅度显著高于正常量。

**为什么重要**：
- 传统量价分析认为"量价齐升才健康"，r1 数据显示相反——缩量上涨延续性更强；
- 如果成立，缩量端可直接用于趋势策略的加仓/持仓信号，比放量反转更有交易价值（因为方向与趋势一致）；
- 这是因子调节器假设的另一半，r1 只验证了放量端。

**检验内容**：
1. 缩量组 vs 正常量组的 MRET/MADEV/RVOL IC 差异（r1 已有初步数据，需 bootstrap CI）；
2. 缩量幅度（z∈[−1.5,−0.5] vs z<−1.5）的剂量-反应关系；
3. 缩量持续天数（连续 N 根缩量）是否增强信号；
4. 时间 OOS + LOPO；
5. 与放量端对比：两端哪个预测力更强、更稳健。

**成功判据**：缩量组动量 IC 显著高于正常量组（ΔIC CI 排除 0），OOS 方向一致。

---

### H2：持仓量（OI）区分放量性质（优先级最高）

**问题**：r1 只有价量数据，无法区分"放量增仓"（新资金入场，趋势可能延续）和"放量减仓"（老资金分配，趋势可能反转）。

**假设**：高 s 趋势中，放量增仓（ΔOI>0）的反转效应弱于放量减仓（ΔOI<0）；极端情况下放量增仓可能不反转甚至延续。

**为什么重要**：
- 这是对 r1 核心结论最可能的 refinement——不是所有放量都反转，减仓放量才是分配；
- OI 是期货独有的信息维度，股票没有，可能是真正的 alpha 来源；
- 能解释为什么 r1 中放量效应的量级在品种间差异大（不同品种的持仓结构不同）。

**前提**：确认 1h 数据是否有 OI 字段；如果没有，需要日线 OI 或新数据源。

**检验内容**：
1. 按 ΔOI（5/20 根 bar 的 OI 变化）分三档：增仓/不变/减仓；
2. 在高 s + 放量条件下，比较三档的 r^100 和因子 IC；
3. 检验"放量+减仓"是否比"放量+增仓"显著更弱（更负）；
4. OI 变化率与 z 的交互项；
5. 日线 OI 作为 1h 信号的确认过滤器。

**成功判据**：减仓放量的 Δr 显著负于增仓放量（CI 排除 0）；如果两者无差异，说明 OI 不提供增量信息。

---

### H3：放量调节作用跨周期是否一致（高优先级）

**问题**：r1 在 1h 和日线上都发现了放量反转，但两个周期的因子交互只在 1h 做了。日线、5m 上因子是否同样被调节？

**假设**：成交量对因子方向的调节作用在日线上同样存在但更温和（日线噪声小），在 5m 上更剧烈但噪声更大。

**为什么重要**：
- 如果跨周期一致，说明这是市场微观结构的普遍规律而非 1h 粒度的 artefact；
- 能确定最佳应用周期；
- 5m 可以更精确定位放量发生在日内哪个时段（开盘/盘中/收盘），可能有不同含义。

**检验内容**：
1. 日线：重复 r1 的因子 IC 分组（MRET/MADEV/RSI/VWAP），按日线 volume z 五分位；
2. 5m：计算 5m 成交量同时段 z，检验 5m 放量是否预测更短期（H=20–60 根 5m bar）的因子翻转；
3. 跨周期一致性：比较三个周期的 IC-z 曲线形状；
4. 1h 放量信号在 5m 上的微观结构——放量 bar 内的价格路径（先涨后跌 vs 直接跌）。

**前提**：5m 数据可用；日线 OI/成交量数据已有。

**成功判据**：日线因子 IC 随成交量分组方向一致（不要求量级相同）。

---

### H4：哪些因子真正有增量信息（高优先级）

**问题**：r1 测了 30 个因子，但它们高度相关（MRET50/100/200、MADEV60/120 本质相同）。需要找出在控制其他因子后，哪些因子与放量的交互有独立预测力。

**假设**：30 个因子的放量翻转现象可以被 2–3 个潜在因子解释（价格位置、趋势强度、波动率），其余是冗余的。

**为什么重要**：
- r1 的"25/30 因子翻转"看起来壮观，但可能只是同一个效应在不同因子上的投影；
- 需要正交化后找出真正的条件因子，避免多重共线性导致的虚假显著；
- 对实际应用有意义——知道用哪 2–3 个因子就够了。

**检验内容**：
1. 因子相关矩阵 + 主成分分析，找出潜在维度；
2. 多元交互回归：$r^H = \beta_0 + \sum_i \beta_i f_i + \gamma z + \sum_i \delta_i (f_i \times z) + \epsilon$，用 LASSO/ElasticNet 选显著交互项；
3. 偏回归：控制 MADEV120 后，MRET50 的交互是否还显著；
4. 正交因子（Fama-French 式）：构造大小、价值、动量、波动率因子，看哪个被成交量调节；
5. 条件 IC：在双变量分组中（如控制 MADEV120 后），其他因子是否还有增量。

**成功判据**：识别出 2–3 个独立交互维度；如果所有交互都被一个因子吸收，说明 r1 的多因子翻转是冗余的。

---

### H5：放量调节的时变性与市场状态依赖（中优先级）

**问题**：r1 的 MADEV120 条件 OOS 从 −4.6% 衰减到 −1.8%，且集中在豆粕。效应是否随市场状态（牛市/熊市/高波动/低波动）变化？

**假设**：放量反转效应在牛市末期最强，在牛市初期和熊市中弱；效应强度与市场整体估值/情绪指标相关。

**为什么重要**：
- OOS 衰减说明效应不是恒定的，需要知道什么时候能用、什么时候不能用；
- r1 已经发现高 s 层有效、中低 s 层弱，但这是横截面的 regime；还需要时间序列上的 regime（市场整体牛熊）；
- 如果效应在特定市场状态下才成立，需要做因子择时。

**检验内容**：
1. 滚动 60 天 IC：观察因子 IC 差（spike IC − base IC）的时间序列；
2. 按市场整体状态（商品指数趋势、VIX 等价物、整体波动率）分组；
3. 效应在趋势末期（s 开始下降时）vs 趋势中期（s 上升时）的差异；
4. 日历效应：年初/季末/交割月是否不同；
5. 品种特异性：sc 原油效应异常强是否与国际盘联动/夜盘跳空有关。

**成功判据**：识别出效应增强/减弱的可观测条件；如果完全时变不可预测，标记为"需动态监控"。

## 4. 方法论约束（继承 r1 教训）

1. **所有对比在同 s 层内进行**，不跨 regime 混合（KF-19 教训）；
2. **lookback 敏感性作为主规格**，N∈{20,60,120} 必须同时报告（KF-7 教训）；
3. **LOPO 品种留一是必过门槛**，单品种效应不能推广（KF-6/16 教训）；
4. **时间 OOS 必须做**，IS/OOS 70/30 切分，切点 IS 确定后冻结（KF-17 教训）；
5. **FDR 控制 q<0.1**，多因子检验必须多重比较校正；
6. **cluster bootstrap by (symbol, session_date)**，不用简单 t 检验；
7. **后窗 H≥60**，短期窗口会漏信号（KF-11 教训）；
8. **报告绝对收益和相对 baseline**，不只报 Δ（KF-13/18 教训）。

## 6. 成功标准

r2 的成功不是"找到更多翻转因子"，而是回答：

1. **缩量端能否独立作为趋势确认信号？**（H1）
2. **OI 能否区分"好放量"和"坏放量"？**（H2）
3. **30 个因子的翻转能否精简到 2–3 个正交维度？**（H4）
4. **效应在什么市场状态下可信、什么状态下失效？**（H5）

如果这四个问题都有明确答案（无论正负），r2 即可收敛。跨周期一致性（H3）是加分项，不是必要条件。
