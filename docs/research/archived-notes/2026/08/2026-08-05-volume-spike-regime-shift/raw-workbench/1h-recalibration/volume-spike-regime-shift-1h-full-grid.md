## 二、两个不同的稳定区，不是一个

### 稳定区 A：短 N + 中 H（跨品种最广）

| 参数 | 范围 |
|---|---|
| N | **20–40**（短 lookback） |
| H | **80–150**（约 16–30 个交易日） |
| n_spike | 614–1117（N=20 z0=1.5 最多） |
| **n_prefix** | **8–12（全品种覆盖）** |
| sign 一致率 | 75–90% |
| Δ 量级 | −0.7% ~ −1.1% |
| p | 全部 <0.01 |

这是最有价值的区域：**N=20 或 30 就够了**，能覆盖全部 12 个品种（黑色/有色/能化都在），效应在 H=80 开始显著、H=100–120 饱和、H=180 略有衰减。

### 稳定区 B：长 N + 长 H（效应最大但品种少）

| 参数 | 范围 |
|---|---|
| N | **60–120**（长 lookback） |
| H | **120–180**（约 24–36 个交易日） |
| n_spike | 531–890 |
| **n_prefix** | **仅 3（c/cs/m 农产品）** |
| sign 一致率 | 100% |
| Δ 量级 | −1.0% ~ −2.1% |
| p | <0.01 |

效应量级更大（N=80 H=180 达 −2.09%），但只在农产品上成立——因为只有农产品有足够长的连续 1h 历史。

## 三、关键发现

### 1. H=120 不是"最优准确值"

效应在 H=80–150 形成宽阔高原（短 N 区），H=100–120 是饱和点，H=180 短 N 开始衰减。选 H=100–120 都可以，不需要精确。

### 2. **N=20 全品种有效**——之前"1h 证伪"是 H 太短

之前 1h 研究用 H=20（~4 天），效应还没展开（N=20 H=20 p=0.45）。把 H 拉长到 80–120 后，**N=20 这个最短的 lookback 就在全部 12 个品种上显著**，sign 一致率 89%。

### 3. N 的作用是"识别什么类型的放量"

- 短 N（20–40）：识别相对近期成交的异常，事件多（800–1100），覆盖所有品种，效应中等（−0.7% ~ −1.0%）；
- 长 N（60–120）：识别相对于更长历史的极端放量，事件少（500–850），只在农产品上可算，效应大（−1.4% ~ −2.1%）且需要更长 H 展开。

两者捕捉的不是同一种事件，但都指向同一个方向。

### 4. z0 不敏感

z0=1.5 和 z0=2.0 的矩阵几乎相同，z0=1.5 事件更多。推荐 z0=1.5 作为主规格。

### 5. 短 N 的"短窗 σ 噪声"问题在长 H 下不影响方向

之前 Stage 7 发现 N=20 的左尾效应是 artefact，那是波动率/尾部度量。方向收益在 N=20 下与 N=30/40/80 一致为负，且跨 12 品种稳健——说明方向信号不是短窗 σ 噪声制造的。

## 四、推荐主规格（更新）

| 参数 | 推荐 | 理由 |
|---|---|---|
| **N** | **20**（或 30） | 覆盖全部 12 品种；效应与更长 N 一致；预热短 |
| **H** | **100–120** | 效应饱和高原；约 20–24 个交易日 |
| **z0** | **1.5** | 事件最多（N=20 时 1117 个），效应不弱于 z0=2 |
| baseline | \|Z\|<0.5 | 未变 |

**推荐 N=20 H=100 z0=1.5**：Δ=−1.11%，p<0.001，12 个品种 90% sign 一致，1117 个 spike。这比之前推荐的 N=80 H=120 更优——品种覆盖从 3 个扩到 12 个，效应量级略小但更普适。

如果要追求最大效应且只做农产品，N=80 H=150–180 是另一选择（Δ=−1.7% ~ −2.1%）。
