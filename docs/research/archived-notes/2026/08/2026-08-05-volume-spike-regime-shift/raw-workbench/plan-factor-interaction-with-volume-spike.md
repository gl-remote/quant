# 探索计划：放量背景下动量/成交量因子的预测力变化

> 日期：2026-08-05
> 周期：1h 主，日线对照
> 基线结论：[volume-spike-trend-exhaustion-1h-daily-findings.md](volume-spike-trend-exhaustion-1h-daily-findings.md)
> 状态：计划，待执行

---

## 0. 研究动机

基线研究确立了一个关于 **volume spike 本身**的结论：

- 在高市场强度（$s_{\text{pre}}>0.10$）的上涨趋势中，成交量同时段 z≥1.5 的放量后 100 根 bar 跑输同 regime baseline 约 2.0%~2.4%；
- 机制是放量**反转漂移 ν 而不改变波动 σ**，相当于把 s 从正值推向负值；
- 这是一个 regime-change 事件，但只使用了价格 + 成交量两个维度。

本计划要回答的下一层问题是：**volume spike 是否也会改变其他常见因子的预测力？** 即把放量当作"条件事件"，比较同一因子在放量日 vs 普通日的 IC、收益分布、多空收益差，看哪些因子会在放量背景下失效、增强、或反向。这有两个价值：

1. **因子择时**：知道一个因子在放量后是否还能用，决定策略是否需要在 spike 事件时降权/平仓/反向；
2. **理解机制**：如果所有"追涨"类因子在放量后普遍失效，而"反转"类因子增强，就进一步支持 exhaustion 机制；如果只有部分因子受影响，能定位是哪类交易者行为在起作用。

---

## 1. 数据与基础口径

- **周期**：1h K 线（主），日线（对照）；26 个期货合约、12 个 prefix；
- **放量定义**（沿用基线）：
  - 同时段 z-score $Z_t \ge 1.5$（N=20 by hour-of-day）；
  - baseline（普通日）：$|Z_t| < 0.5$；
  - 中间区（0.5≤|Z|<1.5）不参与对比，避免模糊地带。
- **市场状态分层**（关键，避免混淆）：
  - 高 s：$s_{\text{pre}}=\text{mean}(r_{t-100:t})/\text{std}(r_{t-100:t}) \ge 0.10$；
  - 低 s：$s_{\text{pre}} \le -0.10$；
  - 中间 s：其他；
  - 所有因子对比必须**在同一 s 层内**进行（否则放量样本本来就偏高 s，会混淆）。
- **预测目标**：$r_{t+1:t+H}$，$H\in\{20, 60, 100, 150\}$（对应 4/12/20/30 天）。
- **统计方法**：
  - Spearman rank IC（因子值与未来收益的截面/时序相关）；
  - 多空组合收益：按因子分 5 档，Q5−Q1 收益；
  - cluster bootstrap by `(symbol, session_date)`，2000 次；
  - 比较 spike 组 vs baseline 组的 IC 差异和多空收益差异。

## 2. 待检验因子

### 2.1 动量/趋势类

| 因子 | 定义 | 假设 |
|---|---|---|
| **MRET(L)** | 过去 L 根 bar 累计对数收益，L∈{20, 50, 100, 200} | 基线已显示高 s 下放量后中期反转；预期 MRET 在放量后预测力**翻转**（正→负） |
| **SUE-style 强度** | $s_{\text{pre}}=\nu/\sigma$（per-bar Sharpe） | 同上，预期高 s 放量后反向 |
| **均线偏离** | $(P_t - \text{MA}_L)/\text{MA}_L$，L∈{20, 60, 120} | 放量后偏离大概率收敛 |
| **MACD/动量振荡器** | DIF−DEA 或类似 | 预期顶部背离时放量失效 |
| **52 周/区间高位** | $(P_t - \min(L))/(\max(L)-\min(L))$，L=100/200 | 接近高位+放量是典型 exhaustion |
| **连续上涨天数** | 过去 K 根 bar 中阳线比例/连续阳线长度 | 极端值+放量应反转 |
| **路径效率** | $\|P_t-P_{t-L}\|/\sum\|r_i\|$（趋势平滑度） | 高路径效率（单边趋势）+放量应更易反转 |

### 2.2 反转/超跌类

| 因子 | 定义 | 假设 |
|---|---|---|
| **短期反转** | $-r_{t-5:t}$ 或 $-r_{t-20:t}$ | 放量后短期（H=20）可能增强反弹，特别是低 s 侧 |
| **RSI(L)** | L=14/30 的相对强弱 | 超买+放量见顶；超卖+放量可能反弹 |
| **布林带位置** | $(P_t-\text{MA}_{20})/(2\sigma_{20})$ | 触及上轨+放量应回归 |
| **K 线形态** | 长上影线、吞没形态、锤子线 | 放量长上影是典型分配信号 |

### 2.3 波动率/风险类

| 因子 | 定义 | 假设 |
|---|---|---|
| **已实现波动** | $\sigma_L = \text{std}(r_{t-L:t})$，L∈{20,60} | 基线显示放量前 σ 已高、放量后不变；预测 σ 本身可能无差异 |
| **ATR/振幅** | L=14 的 ATR 或 $(H-L)/C$ | 同上 |
| **波动率变化** | $\sigma_{20}/\sigma_{60}-1$ | 波动率扩张+放量可能预示趋势结束 |
| **偏度/峰度** | 过去 L 根收益的偏度、峰度 | 负偏+放量可能是恐慌 |
| **Parkinson/ Garman-Klass** | 基于 H/L 的波动率估计 | 与 close-to-close 对比 |

### 2.4 成交量类（基线已部分覆盖）

| 因子 | 定义 | 假设 |
|---|---|---|
| **Volume z-score** | 基线主因子 $Z_t$ | 已知：高 s 下放量反转 |
| **Volume ratio** | $V_t/\text{median}(V_{t-N:t-1})$ | 预期与 z-score 类似，更稳健 |
| **Volume percentile** | $V_t$ 在过去 N 根的百分位 | 非参数版本 |
| **量价相关** | 过去 L 根 corr(r, ΔV) | 放量上涨（正相关）+ 极端值可能反转 |
| **OBV 斜率** | On-Balance Volume 的线性回归斜率 | OBV 背离（价涨 OBV 平）+放量是分配信号 |
| **Accumulation/Distribution** | $\text{ADL}=\sum \frac{(C-L)-(H-C)}{H-L}\cdot V$ 的变化 | 负 ADL + 放量 = 分配 |
| **量能加权价格** | VWAP 偏离 $(P_t-\text{VWAP}_L)/\text{VWAP}_L$ | 高于 VWAP + 放量 = 散户接盘 |
| **持仓量 OI 变化** | $\Delta\text{OI}_L$（如果数据可用） | 放量+减仓=获利了结；放量+增仓=新趋势 |
| **Volume 自相关/聚集** | 过去 L 根 volume 的 AR(1) | 高聚集+放量可能是信息事件 |

### 2.5 流动性/微观结构类

| 因子 | 定义 | 假设 |
|---|---|---|
| **Amihud illiquidity** | $\|r_t\|/(V_t\cdot P_t)$，L 日均值 | 放量时 Amihud 下降，后续收益可能不同 |
| **Kyle's lambda 近似** | $\|r_t\|/\sqrt{V_t}$ | 放量伴随高 lambda = 信息交易 |
| **Bid-ask spread 代理** | $(H-L)/C$ 或 Corwin-Schultz | 放量时 spread 变化 |
| **成交量集中度** | 过去 L 根最大 volume 占比 | 单日极端集中 + 放量 = 事件驱动 |

## 3. 检验设计

### 3.1 主检验：因子 IC 在放量 vs 普通日的差异

对每个因子 $f$ 和每个 horizon $H$：

$$\text{IC}_{\text{spike},s,H} = \text{Spearman}(f_t,\ r_{t+1:t+H} \mid Z_t\ge1.5,\ s_{\text{pre}}\in s)$$
$$\text{IC}_{\text{base},s,H} = \text{Spearman}(f_t,\ r_{t+1:t+H} \mid |Z_t|<0.5,\ s_{\text{pre}}\in s)$$

报告：
- 两组 IC 各自的值与显著性；
- $\Delta\text{IC} = \text{IC}_{\text{spike}} - \text{IC}_{\text{base}}$ 及其 bootstrap CI；
- 按 s 层（高/中/低）分别报告。

**预期模式（如果 exhaustion 机制成立）**：

| 因子类型 | 普通日 IC | 放量日 IC | 解释 |
|---|---|---|---|
| 趋势/动量 | 正（可能弱） | **负或翻零** | 放量打断趋势延续 |
| 短期反转 | 弱负/零 | **更负（高 s）或更正（低 s）** | 对称翻转 |
| 波动率 | 接近 0 | 接近 0 | 基线显示 σ 不变 |
| 成交量本身 | 0 | **负（高 s）** | 基线结论 |
| 量价背离 | 弱 | **增强** | 放量使背离信号更可靠 |

### 3.2 多空组合对比

按因子值分 5 档（在每个 s 层内），计算 Q5−Q1 收益：

$$\text{LS}_{\text{spike}} = \bar{r}_{Q5,\text{spike}} - \bar{r}_{Q1,\text{spike}}$$
$$\text{LS}_{\text{base}} = \bar{r}_{Q5,\text{base}} - \bar{r}_{Q1,\text{base}}$$

比较两个 LS 的差异。这比 IC 更接近实际可交易性。

### 3.3 交互回归

pooled 回归：

$$r_{t+1:t+H} = \beta_0 + \beta_1 f_t + \beta_2 \text{spike}_t + \beta_3 (f_t \times \text{spike}_t) + \beta_4 s_{\text{pre}} + \epsilon$$

- $\beta_1$：因子在普通日的预测力；
- $\beta_3$：**放量是否改变因子预测力**（核心系数）；
- 如果 $\beta_3$ 与 $\beta_1$ 符号相反且显著，说明放量**翻转**了该因子；
- 如果同号，说明放量**增强**；
- 如果 β3≈0，因子不受放量影响。

### 3.4 条件增强检验

对每个因子，检验"因子极端值 + 放量"是否比单独任一条件更强：

- 比如"高 MRET(100) + 放量" vs "高 MRET(100) 不放量" vs "放量但 MRET 不极端"；
- 这验证因子与 volume spike 是否有**增量信息**，而不只是相关。

### 3.5 跨周期验证

- 1h 主检验；
- 日线重复（日线 spike 定义见基线 §5）；
- 跨周期方向应一致，量级可不同。

---

## 4. 多重比较控制

- 因子数量 ~30，horizon 4 个，s 层 3 个 → 约 360 个检验；
- 使用 **Benjamini-Hochberg FDR** 控制 q<0.1；
- 同时报告原始 p 和 FDR 调整后 q；
- 只把跨 s 层、跨 horizon 方向一致的结果标为稳健；
- 优先报告有机制解释的因子，不做数据挖掘式的"全因子显著"列表。

## 5. 预期产出

1. **因子分类表**：哪些因子在放量后预测力翻转、增强、不变、失效；
2. **最强交互因子**：β3 最显著的 3–5 个因子，作为后续策略信号；
3. **机制确认/否定**：如果"追涨类因子普遍在放量后失效"，支持 exhaustion；如果只有成交量类因子受影响，说明只是 baseline 结论的重复；
4. **可交易规则**：例如"高 s 趋势中，MRET(100)>5% 且 z≥1.5 → 减仓"比单纯放量更精确；
5. **更新 findings 文档**：把交互因子结论加入 §2 或新增 §3。

---

## 6. 风险与注意事项

1. **样本量**：放量 + 高 s + 因子极端值的三重条件可能 n<50，需要报告样本量并谨慎解读；
2. **截面 vs 时序**：期货品种少（12 个 prefix），纯截面 IC 不稳定；主要用时序 IC 和组合收益；
3. **重叠样本**：H=100 的收益窗口重叠，用 cluster bootstrap 而非简单 t 检验；
4. **前视偏差**：所有因子只用 t 及之前数据，z-score/rolling 不能包含 t；
5. **OI 数据**：需要确认 1h 数据是否带持仓量字段，如果没有这部分因子标注"待数据"；
6. **与基线的关系**：基线已证伪"无条件放量"效应，本计划只在**有 s 分层**的条件下做，避免重复基线错误；
7. **不做策略回测**：本阶段只检验因子预测力变化，不做成本/仓位/择时回测。

## 8. 成功判据

- 至少 3 个因子在 FDR q<0.1 下显示显著的 ×spike 交互（β3）；
- 结果方向跨 H=60/100 一致；
- 至少 1 个因子在日线重复；
- 能给出明确的"放量后应该用什么因子、不应该用什么因子"的实践结论。

如果所有因子的 β3 都不显著，说明放量只是一个独立事件，不改变其他因子的预测力——这也是有价值的负结果。
