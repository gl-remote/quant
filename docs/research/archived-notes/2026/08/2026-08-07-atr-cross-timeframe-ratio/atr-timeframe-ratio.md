## 2. 研究问题

不同自然周期上的 ATR 是否携带不同的波动率结构信息？本研究观察：

```text
R_t = ATR_high(t) / ATR_low(t)
```

其中第一轮以 `ATR_1h / ATR_15m` 为主。

本研究不把比值高/低直接解释为趋势强/弱，而是进一步判断比值变化由哪一侧驱动：

- 高周期 ATR 扩张：更高时间尺度的波动率正在释放；
- 低周期 ATR 压缩：短周期波动枯竭，但高周期未必主动扩张；
- 低周期 ATR 扩张：盘中短波动或噪声占主导；
- 高周期 ATR 收缩：高周期波动率退潮。

## 3. 术语约定

| 术语 | 含义 |
|---|---|
| 高周期 | 时间尺度更大的周期，第一轮指 1h |
| 低周期 | 时间尺度更小的周期，第一轮指 15m |
| `H_t` | 高周期 ATR，第一轮为 `ATR_1h_t` |
| `L_t` | 低周期 ATR，第一轮为 `ATR_15m_t` |
| `S_H` | 高周期同周期短长 ATR 比，`ATR_1h(14) / ATR_1h(50)`，识别高周期内部压缩/扩张 |
| `S_L` | 低周期同周期短长 ATR 比，`ATR_15m(56) / ATR_15m(200)`，识别低周期内部压缩/扩张 |
| `state_S` | 由 `S_H`、`S_L` 相对 1 的大小构成的四象限，用于判断主导周期 |
| 跨周期比值 | 高周期 ATR / 低周期 ATR，如 `ATR_1h / ATR_15m` |
| 同周期比值 | 同一周期上短窗 ATR / 长窗 ATR，如 `ATR(14)/ATR(50)`；本研究用作主导周期识别主因子 |
| bar 对齐口径 | 两个周期使用相同 ATR bar 数，但覆盖的物理时间不同 |
| 时钟对齐口径 | 两个周期 ATR 覆盖相同物理时间窗口 |
| 累计变化 | 一段时间内 ATR 的对数变化，即 `log(ATR_t / ATR_{t-k})` |
| 变化速度 | ATR 一阶差分的移动平均，即最近每根 bar 的平均变化；辅助备选 |
| 高周期主导 | 同周期短长比显示高周期扩张而低周期未扩张 |
| 低周期主导 | 同周期短长比显示低周期扩张而高周期未扩张 |
| 共振扩张 | 高周期、低周期同周期短长比均大于 1 |
| 共振压缩 | 高周期、低周期同周期短长比均不大于 1 |

## 4. 核心变量

### 4.1 主口径：bar 对齐

```text
R_bar = ATR_1h(14) / ATR_15m(14)
```

- 分子、分母均使用 14 根各自周期的 bar；
- 覆盖的物理时间不同：约 14 小时 vs 约 3.5 小时；
- 该口径天然混合“周期尺度差异”和“记忆窗口差异”，用于观察跨周期结构。

### 4.2 对照口径：时钟对齐

```text
R_clock = ATR_1h(14) / ATR_15m(56)
```

- 分子、分母均覆盖约 14 小时；
- 用于排除“14 根 1h vs 14 根 15m 记忆长度不同”造成的机械差异；
- `sqrt(4)` 只作为随机游走 sanity reference，不作为交易阈值。

### 4.3 后续扩展

```text
ATR_15m / ATR_5m
ATR_daily / ATR_1h
```

## 5. 因子族

### A. 跨周期比值因子

| 因子 | 定义 | 用途 |
|---|---|---|
| `R_bar` | `H / L` | 主观察变量 |
| `log_R_bar` | `log(R_bar)` | 降低右偏 |
| `R_bar_pct_100` | 每合约滚动 100 根 1h 的 `R_bar` 分位 | 判断本合约近期比值高低 |
| `R_bar_z_100` | 滚动 100 根 1h 的 `R_bar` z-score | 异常放大/压缩 |
| `R_bar_excess` | `log_R_bar - rolling_median(log_R_bar)` | 相对近期中枢的偏离 |
| `R_clock` | `ATR_1h(14) / ATR_15m(56)` | 时钟对齐对照值 |
| `R_clock_excess` | `log_R_clock - rolling_median(log_R_clock)` | 时钟对齐下的结构偏离 |

### B. 单周期 ATR 水平因子

| 因子 | 定义 | 用途 |
|---|---|---|
| `H_pct_100` | `H` 在过去 100 根 1h 的分位 | 判断高周期波动率水平 |
| `L_pct_400` | `L` 在过去 400 根 15m 的分位 | 判断低周期波动率水平 |
| `H_z_100` | `H` 滚动 z-score | 高周期异常波动 |
| `L_z_400` | `L` 滚动 z-score | 低周期异常波动 |
| `H_norm` | `H / close` | 跨合约可比的高周期归一化 ATR |
| `L_norm` | `L / close` | 跨合约可比的低周期归一化 ATR |
| `common_vol` | `sqrt(H_norm * L_norm)` 或二者分位均值 | 总体波动环境 |

### C. 同周期短长 ATR 比值因子（主导周期识别 · 主因子）

对每个周期单独计算短窗 ATR / 长窗 ATR：

```text
S_H = ATR_1h(short) / ATR_1h(long)
S_L = ATR_15m(short) / ATR_15m(long)
```

含义与社区中已有的“同周期 ATR Ratio / ATR squeeze”一致：

- `S > 1`：该周期短窗波动高于自身长窗，处于扩张状态；
- `S < 1`：该周期短窗波动低于自身长窗，处于压缩状态；
- `S` 在两个周期上各自归一到自身尺度，不需要跨周期数量级对齐。

第一轮使用时钟对齐窗口，避免记忆长度不同：

- 高周期短窗 = 14 根 1h；
- 高周期长窗 = 50 根 1h；
- 低周期短窗 = 56 根 15m（≈14h）；
- 低周期长窗 = 200 根 15m（≈50h）。

| 因子 | 定义 | 含义 |
|---|---|---|
| `S_H` | `ATR_1h(14) / ATR_1h(50)` | 高周期内部波动压缩/扩张 |
| `S_L` | `ATR_15m(56) / ATR_15m(200)` | 低周期内部波动压缩/扩张 |
| `S_H_pct` | `S_H` 在每合约滚动 100 根 1h 的分位 | 高周期内部压缩/扩张的相对位置 |
| `S_L_pct` | `S_L` 在每合约滚动 400 根 15m 的分位 | 低周期内部压缩/扩张的相对位置 |
| `S_diff` | `S_H - S_L`（或分位差 `S_H_pct - S_L_pct`） | 哪个周期相对自身更扩张；>0 高周期主导，<0 低周期主导 |
| `S_ratio` | `log(S_H / S_L)` | 两周期内部状态的相对差，用于排序和分位 |
| `state_S` | 由 `(S_H > 1, S_L > 1)` 得到的四象限 | 见下文 |

`state_S` 四象限：

- `S_H > 1, S_L > 1`：双周期共振扩张；
- `S_H > 1, S_L ≤ 1`：高周期独扩，低周期仍压缩；
- `S_H ≤ 1, S_L > 1`：低周期独扩，高周期仍压缩；
- `S_H ≤ 1, S_L ≤ 1`：双周期共振压缩。

与跨周期比值 `R_bar = H / L` 的关系：

- `R_bar` 回答“高周期 ATR 相对低周期 ATR 有多大”；
- `S_H / S_L` 回答“哪个周期相对自身常态更扩张”；
- 两者正交：`R_bar` 高可能来自 `S_H` 高（高周期真扩张）或 `S_L` 低（低周期压缩），这正是我们要拆的核心；
- 因此“跨周期比值 × 同周期短长比”是第一组关键二维分层。

### D. 累计变化因子（辅助）

时钟对齐：高周期回看 `k` 根 1h，低周期回看 `4k` 根 15m。第一轮取 `k ∈ {5, 20}`。

| 因子 | 定义 | 含义 |
|---|---|---|
| `dLogH_k` | `log(H_t / H_{t-k})` | 高周期 ATR 累计扩张/收缩 |
| `dLogL_k` | `log(L_t / L_{t-4k})` | 低周期 ATR 累计扩张/收缩 |
| `dLogR_k` | `dLogH_k - dLogL_k` | 跨周期比值累计变化方向 |

D 组用于补充 C 组的时间动态：C 组是静态结构状态，D 组是过去一段时间的变化量。两者结合可以区分“已经扩张一段时间”与“刚开始扩张”。

### E. 变化速度因子（辅助备选，不主用）

D 组看一段时间的累计变化；E 组看最近每根 bar 的平均变化速度。该组在跨周期比较时存在数量级问题，需要归一化且分母可能接近 0，因此作为辅助备选，第一轮可以先观察，不参与主分层。

定义一阶差分：

```text
ΔH_t = H_t - H_{t-1}
ΔL_t = L_t - L_{t-1}
```

时钟对齐：高周期 `k` 根 1h，低周期 `4k` 根 15m。第一轮取 `k ∈ {5, 20}`。

| 因子 | 定义 | 含义 |
|---|---|---|
| `MAΔH_k` | `SMA(ΔH, k)` | 高周期 ATR 平均变化速度 |
| `MAΔL_4k` | `SMA(ΔL, 4k)` | 低周期 ATR 平均变化速度 |
| `MAΔH_norm_k` | `SMA(ΔH / H, k)` | 高周期相对变化速度，无量纲 |
| `MAΔL_norm_4k` | `SMA(ΔL / L, 4k)` | 低周期相对变化速度，无量纲 |
| `vel_diff_k` | `MAΔH_norm_k - MAΔL_norm_4k` | 高/低周期速度差 |
| `vel_sign_H_k` | `sign(MAΔH_k)` | 高周期扩张/收缩/持平 |
| `vel_sign_L_4k` | `sign(MAΔL_4k)` | 低周期扩张/收缩/持平 |
| `vel_state_k` | `(vel_sign_H_k, vel_sign_L_4k)` | 四象限速度状态 |

注意：

- 不可直接比较 `MAΔH_k` 与 `MAΔL_4k` 的绝对量级，必须使用 `_norm` 版本；
- E 组只在 C/D 组已经识别状态后用于识别“衰竭”或“拐头”，不单独主用；
- 若 C 组显示高周期扩张但 E 组高周期速度已转负，可能表示扩张衰竭。

### F. 跨周期比值持续性因子

| 因子 | 定义 | 用途 |
|---|---|---|
| `R_rank_chg_5` | 当前 `R_bar` 分位 - 5 根 1h 前分位 | 跨周期比值正在上升/回落 |
| `R_persistence` | 当前 `R_bar` 处于高/低三分位的连续 bar 数 | 瞬时冲击 vs 持续制度 |
| `R_accel_5` | `dLogR_5 - dLogR_20` | 跨周期比值累计变化加速/减速 |
| `R_vs_MA20` | `R_bar / SMA(R_bar, 20) - 1` | 相对短期中枢偏离 |

### G. 跨期限结构因子

后续把多个周期串成期限结构：

| 因子 | 定义 |
|---|---|
| `R_15_5` | `ATR_15m / ATR_5m` |
| `R_d_1h` | `ATR_daily / ATR_1h` |
| `term_slope` | `R_d_1h - R_bar - R_15_5` 的标准化组合 |
| `term_curve_state` | 三个跨周期比值分别处于高/中/低三分位的组合状态 |

### H. 候选交互因子

H 组只做观察，不参与第一轮调参。

| 交互 | 观察问题 |
|---|---|
| `R_bar_pct × S_H_pct` | 高跨周期比值是来自高周期内部扩张还是低周期内部压缩 |
| `R_bar_pct × S_L_pct` | 低跨周期比值是否来自低周期内部独扩 |
| `S_H_pct × S_L_pct` | 同周期短长比四象限对应的后续收益和波动 |
| `R_clock_excess × R_bar_excess` | bar 对齐与时钟对齐是否互相验证 |
| `state_S × dLogH_20` | 同周期状态叠加累计变化，识别扩张阶段 |
| `state_S × vel_sign_H_5` | 同周期状态叠加变化速度，识别衰竭/拐头 |

## 6. 初步状态解释

跨周期比值与同周期短长比是两个正交维度，核心分层先看这两个维度：

| `R_bar` | `S_H` | `S_L` | 状态 | 初步解释 |
|---|---|---|---|---|
| 高 | >1 | ≤1 | 高周期独扩 | 高周期波动主动释放，低周期仍压缩；最有“趋势/冲击启动”含义 |
| 高 | ≤1 | <1 | 低周期被动压缩 | R 高是分母压低造成，不能解释为高周期扩张 |
| 高 | >1 | >1 | 共振扩张中 | 两周期都在扩张，R 不再区分主导方，需要看 D/E 组判断阶段 |
| 低 | ≤1 | >1 | 低周期独扩 | 短周期波动占主导，可能是噪声或事件冲击，高周期尚未确认 |
| 低 | <1 | ≤1 | 高周期冷却 | 高周期波动退潮，趋势衰减 |
| 低 | <1 | <1 | 共振压缩 | 双周期都在压缩，等待后续波动释放；这是同周期 ATR squeeze 文献最关注的状态 |

辅助判断：

- `dLogH_k`、`dLogL_k` 用于区分“刚开始扩张”和“已经扩张一段时间”；
- `vel_sign_H_k`、`vel_sign_L_4k` 用于识别扩张衰竭或拐头。

## 7. 第一轮分析计划

### 7.1 数据

- 使用本地 15m 与 1h CSV；
- 每合约独立计算，不跨合约池化阈值；
- 第一轮只覆盖数据完整的合约；
- ATR 使用 14 bar Wilder ATR 作为基础短窗，长窗取 50 bar。

### 7.2 时间对齐

- 以 1h bar 收盘时间为主索引；
- 取同一时刻已完成的 15m ATR；
- 禁止使用未来 15m bar；
- 对齐后单独记录缺失、夜盘跳空和合约上市前空窗。

### 7.3 必算因子

第一轮至少计算 A-D、F 组；E 组（差分速度）作为备选先观察；G/H 组只做交互观察。

### 7.4 分层方法

1. 先按 `R_bar_pct_100` 三分位；
2. 再按 `state_S`（由 `S_H`、`S_L` 得到的四象限）拆分，这是第一组核心二维分层；
3. 再用 `H_pct_100`、`L_pct_400`、`dLogH_5`、`dLogL_20` 做三维拆分，判断扩张阶段；
4. 同时观察 `R_bar` 与 `R_clock`，若两者结论不一致，需要单独解释；
5. E 组只用于在已经识别的状态上判断衰竭/拐头，不单独主用。

### 7.5 响应变量

- 未来 5 / 20 / 100 根 1h 的简单收益；
- 未来 5 / 20 / 100 根 1h 的绝对收益；
- 未来 `H`、`L`、`R_bar`、`S_H`、`S_L` 的变化；
- 趋势延续 vs 均值回归；
- 路径效率；
- 波动继续扩张 vs 收缩；
- 板块、年份、交易时段差异。

### 7.6 稳健性

- 独立样本按合约/日期聚类，不把重叠 bar 当独立样本；
- 同时报告 event 数和独立日/合约日数；
- 不使用全品种统一阈值直接定义交易信号；
- 第一轮先观察结构，不定义完整策略；
- 若结果由单一品种或单一年份主导，必须降级为观察；
- 不做随机/基准对照前，不宣称 alpha。

## 8. 禁止事项

- 不把 R 高直接解释为“趋势强”；
- 不把 R 低直接解释为“震荡”；
- 不混用 bar 对齐和时钟对齐口径；
- 不把同周期短长 ATR 比与跨周期 ATR 比混为一谈；
- 不直接比较未归一化的高/低周期 ATR 差分；
- 不跨合约池化阈值后再得出交易结论；
- 不把重叠 event 数当作独立样本数；
- 不在未做样本外/基准验证前宣称可交易 alpha。
