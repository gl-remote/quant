# 阶段性收尾：从交易信号探索回归市场分层研究主线

## 元信息

- 主题：atr-timeframe-ratio
- 类型：阶段性总结与方向校准
- 日期：2026-08-07
- 覆盖阶段：Stage 1–9 + VRP 验证

## 1. 研究初心

本研究的原始问题是：

> 不同周期 ATR 的比值能否刻画市场状态分层？

具体来说，`R_bar = ATR_1h / ATR_15m` 及其配套因子（S_H/S_L 同周期短长比、dLogH/dLogL 累计变化、MAΔH/MAΔL 变化速度等）能否识别不同的波动制度，并解释不同制度下的市场行为差异。

**研究目标是理解市场结构，不是构建单一交易信号。**

## 2. 已完成的工作

### 2.1 因子设计与分布（Stage 1）

- 完成 A–G 七组因子设计；
- 32 合约、12,610 个 1h 样本的 EDA；
- R_bar 中位数 1.82（低于理论值 2.0），右偏、紧凑；
- S_H/S_L 四象限：双压缩 56.5%、共振扩张 29.1%、H_only 9.7%、L_only 4.8%；
- R_bar 高低主要由高周期驱动，不是低周期压缩。

### 2.2 H_only 路径的深入探索（Stage 3–9）

Stage 1 发现 H_only 是最不常见但最有信息量的状态，随后做了 7 个阶段的追踪：

| 阶段 | 核心发现 |
|---|---|
| Stage 3 | H_only confirmed 后 ret_20 = +0.47%，CI 不含 0 |
| Stage 4 | confirmed 在超卖位置收益更高（+0.98%），方向一致性仅 50% |
| Stage 5 | 成交量/OI/跳空无法预测 confirmed（CV AUC 0.53） |
| Stage 6 | 非重叠后 H_only 首根仍有 +0.49%，但 CI 含 0 |
| Stage 7 | 短脉冲（1–2 根）事后 +1.76%，但属事后选择偏差 |
| Stage 8 | 可执行短脉冲 +0.07%，跑输随机基准 |
| Stage 9 | 加止损后 +0.21%，但正收益来自多头 beta，非信号 alpha |

### 2.3 F 组跨期限结构（R_1h_d）方向信号也已被熊市数据否定

F 组初步发现 R_1h_d（日 ATR / 1h ATR）低三分位做多、高三分位做空的多空组合在 2024–2026 牛市数据上 h=60 收益 +1.82%。下载 2022–2023 熊市数据验证后：

- long_low 在熊市 -0.28%（CI [-0.53%, -0.05%]，显著为负）；
- short_high 在熊市 -0.18%；
- long_short 多空组合在熊市 **-0.44%（CI [-0.77%, -0.12%]）**，完全翻转；
- 详见 [term-bear-validation-archive.md](./term-bear-validation-archive.md)。

**结论：R_1h_d 是方向 beta 放大器，不是市场中性信号。** 它作为波动率状态描述变量仍有价值，但不应用于方向预测。

### 2.4 VRP 意外发现的澄清

- "随机入场 + 止损"的 +0.27% 不是波动率风险溢价；
- 扩展到 2024–2026 年、7,000 笔交易后确认是多头 beta；
- 做空 -1.01%，77% 合约上涨，买入持有 +4.42%；
- 详见 [vrp-validation-report.md](./vrp-validation-report.md)。

## 3. H_only 路径的结论

H_only 作为**独立交易信号**不成立，但作为**市场状态描述变量**仍有价值：

1. **事后描述价值**：H_only 的出现确实标记了高周期波动率独扩的时刻；
2. **无前瞻交易价值**：无法在 t 时刻预测 H_only 会持续多久、是否 confirmed、后续方向；
3. **机制理解**：短脉冲 H_only 更像超卖反弹（恐慌脉冲），长持续 H_only 是高波动震荡；
4. **正收益来源是 beta**：任何只做多策略在 2024–2026 多头市场都能盈利，H_only 无增量 alpha。

## 4. 方法论收获

这段探索虽然没有产出可交易信号，但留下了重要的方法论教训：

1. **事后分组 ≠ 可交易策略**：Stage 7 的 +1.76% 是事后选择偏差，t 时刻无法复制；
2. **必须有随机基准**：没有随机入场对比，Stage 9 的 +0.21% 很容易被误判为 alpha；
3. **必须做空头测试**：只做多的正收益在多头市场中没有信息量，VRP 验证中做空 -1.01%；
4. **前瞻指标 AUC < 0.6 即不可用**：Stage 5 的教训；
5. **非重叠抽样是必须的**：重叠 bar 会严重高估显著性；
6. **止损/止盈会改变收益分布**：但改变本身不等于 alpha，需与无止损和随机基准对比；
7. **out-of-sample 必须包含不同市场环境**：R_1h_d 在 2024–2026 牛市 +0.61%，在 2022–2023 熊市 -0.44%，同一信号方向完全相反；
8. **多空组合不等于 market neutral**：必须在熊市数据上验证组合是否真正中性。

## 5. 回归主线：市场分层研究

H_only 只是 state_S 四象限之一，不应占据全部研究资源。回到原始问题，以下方向尚未充分探索：

### 5.1 四象限的市场环境刻画（描述性研究）

不追求交易信号，而是回答：

- 四种状态（co_compress / co_expand / H_only / L_only）分别对应什么样的市场环境？
- 板块、年份、交易时段的分布差异？
- 状态转换的时间规律（什么时间更容易从压缩转入扩张）？
- R_bar 和 S_diff 能否作为市场"温度计"而非交易信号？

### 5.2 跨期限结构（F 组因子）

- R_15_5、R_d_1h、term_slope 的分布和分层能力；
- 多周期比值串成期限曲线后，曲线形状（陡峭/平坦/倒挂）是否对应不同市场状态；
- 这是原始研究设计中尚未验证的部分。

### 5.3 R_bar 本身的统计特征

- R_bar 的均值回归性质（半衰期、自相关）；
- R_bar 极值后的波动率路径（不预测方向，只预测波动率）；
- R_bar 与实际波动率变化的 lead-lag 关系；
- 这可能直接服务于风险管理（仓位 sizing）而非方向交易。

### 5.4 co_expand 和 co_compress 的深入研究

- Stage 3 发现 co_expand 中 balanced 组（双周期均衡扩张）|r| 最高；
- co_compress 后的波动扩张预测在 1h 周期不成立，但可能在更长周期成立；
- 这两个状态占总样本的 86%，比 H_only 更有研究价值。

### 5.5 扩大数据范围

- 当前数据集中在 2024–2026 年商品多头市场；
- 需要下载 2020–2023 年数据（含熊市和震荡市）；
- 需要降到 15m/5m 周期获取更多事件；
- 需要加入股指期货和国债期货。

## 6. 下一步建议

按优先级：

1. **整理 Stage 1 的描述性发现**，完成市场分层画像（四象限的环境特征、板块差异、时间规律）；
2. **验证 F 组跨期限结构因子**，看多周期比值曲线是否有分层能力；
3. **研究 R_bar 的波动率预测力**（而非方向预测力），服务于仓位管理；
4. **下载更长历史数据**，覆盖熊市和震荡市后重新验证所有发现；
5. 将 H_only 的探索结论归档，不再围绕它构建策略。
