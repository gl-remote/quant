## 1. 问题背景

Stage 4 发现一个反直觉现象：

- H_only confirmed 在 MADEV_60 < 0（下降趋势）中 fwd_ret_20 = +0.87%，显著；
- 在 MADEV_60 > 0（上升趋势）中 fwd_ret_20 = +0.32%，不显著；
- 在 MADEV_60 low（超卖）中 fwd_ret_20 = +0.98%，显著；
- 方向一致性约 50%——收益方向与前置趋势无关。

这说明 H_only confirmed 的正收益可能有两种完全不同的机制在驱动：

1. **超卖反弹**：价格已经持续下跌，高周期波动率突然放大（恐慌/止损），低周期跟进确认后，价格反弹；
2. **趋势启动**：横盘或微跌后，高周期信息驱动波动扩张，低周期确认后，新趋势开始。

本备忘梳理两种机制在微观结构上的区别，并提出可验证的区分方法。

## 2. 触发原因对比

| 维度 | 超卖反弹 | 趋势启动 |
|---|---|---|
| 波动率扩张来源 | 被迫交易：止损单、强平、基金赎回、margin call | 主动交易：新信息（宏观数据、政策、供需变化） |
| 参与者结构 | 流动性提供者 + 空头回补 | 新资金入场 + 趋势跟随者 |
| 价格位置 | 已持续下跌一段时间，价格远离均线 | 可能在任何位置，通常伴随关键位突破 |
| 信息属性 | 无新信息，是仓位调整导致的波动 | 有新信息，是基本面重定价 |
| OI 变化 | OI 下降（老仓平仓） | OI 上升（新资金开仓） |
| 典型时间 | 美股尾盘、国内夜盘、数据公布后的过度反应 | 开盘突破、事件驱动、板块轮动 |

## 3. 波动路径对比

### 3.1 超卖反弹路径

```text
价格持续下跌
  → co_compress（长期压缩，空头积累）
  → H_only（高周期 ATR 突然放大，恐慌性下跌）
  → 可能短暂 L_only（低周期跟跌）
  → co_expand（双周期共振，恐慌出清）
  → 快速 co_compress（流动性回转，反弹结束）
```

特征：

- S_H 脉冲式升高，持续 1–3 根后快速回落；
- 价格 V 型，快跌快涨；
- 成交量急剧放大后萎缩；
- 反弹目标通常是均线或前高附近。

### 3.2 趋势启动路径

```text
横盘/微跌
  → co_compress（波动率压缩，市场等待方向）
  → H_only（高周期 ATR 扩张，新信息定价）
  → H_only 持续多根（S_H 维持 >1，高周期持续扩张）
  → S_L 逐步抬升（低周期慢慢确认）
  → co_expand（双周期共振，趋势确认）
  → co_expand 持续（趋势延续）
```

特征：

- S_H 台阶式升高，持续 5+ 根；
- 价格台阶式运动，回调浅；
- 成交量稳步放大而非脉冲；
- 趋势可能持续数十根。

### 3.3 state_S 状态转换差异

```text
超卖反弹:
  co_compress(长) → H_only(短,1-3根) → co_expand(短) → co_compress
  S_H 脉冲：快速升高 → 快速回落

趋势启动:
  co_compress → H_only(长,5+根) → co_expand(长) → 缓慢 co_compress
  S_H 台阶：逐步升高 → 维持高位 → 缓慢回落
```

## 4. 成交量与 OI 特征对比

| 指标 | 超卖反弹 | 趋势启动 |
|---|---|---|
| 成交量形态 | 急剧脉冲放大 | 稳步放大 |
| vol_chg_1（当根变化） | 高（突然放量） | 中低 |
| vol_slope_5（5 根趋势） | 负（放量后缩量） | 正（持续放量） |
| vol_ratio（相对 20 根均值） | 高（>1.5） | 中（1.0–1.5） |
| OI 变化 | 下降（dLogOI_5 < 0） | 上升（dLogOI_5 > 0） |
| oi_chg_bar（当根 OI 变化） | 大幅负（平仓） | 正（开仓） |
| 量×OI 组合 | vol_up_oi_down（恐慌平仓） | vol_up_oi_up（新资金入场） |
| capitulation 标志 | 可能触发 | 不触发 |

### 4.1 Stage 5 的初步证据

- `vol_up_oi_up` confirmed 后 fwd_ret_20 = 0.66%，CI [0.17%, 1.23%]（趋势启动候选）；
- `vol_up_oi_down` confirmed 率最高（24.5%）但收益 CI 含 0；
- `capitulation`（下降趋势+放量+OI 降）confirmed 率反而最低（12.7%）；
- vol_chg_1 是最强单变量（AUC 0.570），但在非重叠样本中区分度消失。

这些证据暗示**两种机制可能都存在**，但当前样本量不足以可靠拆分。

## 5. 价格路径与持仓策略对比

| 策略要素 | 超卖反弹 | 趋势启动 |
|---|---|---|
| 入场时机 | H_only 首根 + 下跌动能衰竭信号 | H_only 持续 3+ 根 + S_L 开始抬升 |
| 方向 | 逆势（做多下跌中的 H_only） | 顺势（沿 H_only 方向） |
| 最优持仓周期 | 5–10 根（短） | 20–100 根（长） |
| fwd_ret_5 vs fwd_ret_20 | 5 根贡献大部分收益 | 20 根仍在延续 |
| 回撤特征 | 入场后可能继续跌一段才反弹 | 入场后回调浅 |
| 止损 | 较宽（恐慌可能过度） | 较紧（突破失败位） |
| 止盈 | 回到均线/前高 | 移动止盈 |
| 仓位 | 小（反弹不确定） | 大（趋势延续概率高） |
| 风险收益比 | 低（反弹空间有限） | 高（趋势空间大） |

## 6. 可验证的区分变量

以下变量可以在 t 时刻或 t+5 时刻计算，用于事后或事前区分两种机制：

### 6.1 前置趋势位置

| 变量 | 超卖反弹 | 趋势启动 |
|---|---|---|
| MADEV_60 | < 0，且 abs 大（强下降趋势） | ≈ 0 或刚转正 |
| MADEV_20 | < 0 | > 0 或突破 0 |
| ret_60 | 显著为负 | ≈ 0 或微正 |
| 价格相对 60 期均线 | 远低于均线 | 接近均线或刚突破 |
| trend_strength | strong + 方向向下 | weak/mid 或 strong + 方向向上 |

### 6.2 H_only 持续时间

| 变量 | 超卖反弹 | 趋势启动 |
|---|---|---|
| state_duration（H_only 已持续根数） | 1–2 根 | 5+ 根 |
| S_H 峰值 | 高（>1.1）但短暂 | 中（1.0–1.1）但持续 |
| S_H 5 根后变化 | 快速回落到 <1 | 维持 >1 |

### 6.3 量/OI 模式

| 变量 | 超卖反弹 | 趋势启动 |
|---|---|---|
| vol_ratio | > 1.5 | 1.0–1.5 |
| vol_slope_5 | < 0 | > 0 |
| dLogOI_5 | < 0 | > 0 |
| vol_oi_state | vol_up_oi_down | vol_up_oi_up |

### 6.4 跳空

| 变量 | 超卖反弹 | 趋势启动 |
|---|---|---|
| gap 方向 | 向下跳空（恐慌） | 向上突破或无跳空 |
| gap_atr | 大（>0.5） | 小或无 |
| gap_filled | 快速回补 | 不回补 |

### 6.5 前向路径确认（事后标注）

| 变量 | 超卖反弹 | 趋势启动 |
|---|---|---|
| 5 根后 S_H | < 1（回落） | > 1（维持） |
| 20 根后价格 | 回到 H_only 起点附近 | 沿方向持续运动 |
| 20 根后 state_S | co_compress | co_expand |
| fwd_ret_5 vs fwd_ret_20 | ret_5 >> ret_20 | ret_20 >> ret_5 |

## 7. 当前数据的证据倾向

基于 Stage 3–6 已有结果，证据更偏向**超卖反弹机制**：

1. **Stage 4**：confirmed 在下降趋势中超额收益更高（+0.87% vs +0.32%），超卖位置最高（+0.98%），方向一致性 50%；
2. **Stage 3**：H_only 平均持续 4.3 根，中位数 2 根——大部分是短暂脉冲，更符合超卖反弹；
3. **Stage 5**：capitulation 标志 confirmed 率低（12.7%），说明恐慌性 H_only 大多不会被确认，一旦确认反弹力度大；
4. **Stage 5**：large gap + downtrend + confirmed ret_20 = 1.47%，是典型的恐慌跳空后反弹；
5. **Stage 6**：H_only 首根直接入场（不等确认）胜率 61.8%，而等 confirmed 后入场胜率降到 51.9%——说明最佳入场点在恐慌最盛时，而不是趋势确认后。

但也有证据支持趋势启动机制存在：

1. vol_up_oi_up（新资金）confirmed 后收益 0.66%，CI 不含 0；
2. 能化板块 confirmed 收益 1.31%，可能包含事件驱动的趋势启动；
3. H_only 持续 10+ 根的长尾事件（max=35 根）更可能是趋势启动。

**当前判断**：约 70% 的 H_only confirmed 是超卖反弹，30% 是趋势启动，但这个比例需要 Stage 7 用更多数据验证。

## 8. 验证路径

### 8.1 短期（现有数据可做）

1. **按 state_duration 拆分**：H_only 持续 1–2 根 vs 5+ 根，对比前向路径；
2. **按 MADEV_60 方向 × vol_oi_state 四维分组**：
   - 下降趋势 + vol_up_oi_down = 超卖反弹候选
   - 横盘/上升 + vol_up_oi_up = 趋势启动候选
3. **前向路径分类**：用 5 根后 S_H 是否维持 >1 作为事后分类，回看 t 时刻特征；
4. **收益曲线形态**：对比两类事件的 fwd_ret_1 到 fwd_ret_20 累计收益曲线。

### 8.2 中期（需要扩样本）

1. **降到 15m/5m 周期**：以 15m 为高周期、5m 聚合为低周期，独立事件数可能增加 3–4 倍；
2. **下载更多历史数据**：2022–2024 年数据，覆盖不同市场环境；
3. **加入更多合约**：当前 33 个合约集中在农产品和能化，需要股指、国债、更多有色。

### 8.3 长期（如果机制确认）

1. 针对超卖反弹设计专属策略（逆势、短持仓、宽止损）；
2. 针对趋势启动设计专属策略（顺势、长持仓、紧止损）；
3. 两种策略组合，降低相关性。

## 9. 对研究方向的影响

如果超卖反弹是主导机制，那么：

- Stage 5 中"寻找 confirmed 前瞻指标"的方向部分错误——超卖反弹不需要预测 confirmed，而是需要识别"恐慌是否过度"；
- Stage 6 中"H_only 首根直接入场"的逻辑成立——在恐慌最盛时入场，等 confirmed 反而错过最佳价位；
- 未来因子设计应转向：超卖程度（RSI、布林带位置、连续跌幅）、恐慌度量（ATR 脉冲、成交量 z-score）、流动性指标（买卖价差、订单簿深度）。

如果趋势启动也占显著比例，则需要：

- 区分两种机制后分别建模；
- 趋势启动可能需要等 S_L 确认（因为它是真信息驱动，确认后趋势延续概率高）；
- 超卖反弹不需要等确认（因为确认时反弹已经开始）。

## 10. 下一步建议

优先执行第 8.1 节的短期验证：

1. 写脚本按 state_duration 和 MADEV×vol_oi 拆分 H_only 事件；
2. 画两类事件的前向累计收益曲线；
3. 用 5 根后 S_H 路径做事后分类，检验 t 时刻特征的区分度；
4. 基于结果决定是否需要降周期扩样本。

这一步不需要新数据，用 Stage 6 富集面板即可完成。
