## 1. 数据与口径

- 主索引：1h bar 收盘时间；
- 15m ATR 用 `merge_asof(direction="backward")` 对齐，保证只取当时已知值；
- ATR 算法：Wilder ATR；
- 高周期 H：`ATR_1h(14)`，长窗 `ATR_1h(50)`；
- 低周期 L：`ATR_15m(56)`（≈14h，时钟对齐），长窗 `ATR_15m(200)`（≈50h）；
- 所有分位数在每合约内部滚动计算，不跨合约池化；
- 本轮仅做描述与相关分析，未涉及未来收益。

## 2. R_bar 整体分布

`R_bar = ATR_1h(14) / ATR_15m(56)`，即高/低周期各自 14 bar 数下的 ATR 比值。

| 统计量 | 值 |
|---|---:|
| n | 12,610 |
| mean | 1.830 |
| median | 1.816 |
| std | 0.128 |
| min | 1.432 |
| p05 | 1.644 |
| p25 | 1.741 |
| p75 | 1.904 |
| p95 | 2.055 |
| max | 2.828 |
| skew | 0.761 |
| kurtosis | 1.563 |

log 变换后：`log_R_bar` mean = 0.602，std = 0.069，skew = 0.48，分布明显更对称。

时钟对照片值：

| 统计量 | R_clock |
|---|---:|
| mean | 1.735 |
| median | 1.719 |
| std | 0.343 |
| p05 / p95 | 1.197 / 2.297 |

### 2.1 关键观察

- R_bar 中位数 **1.82**，R_clock 中位数 **1.72**，均显著低于随机游走理论值 `sqrt(4) = 2.0`；
- 说明商品期货在 15m–1h 尺度上不满足随机游走缩放，真实波动具有正自相关/波动聚集，使得高周期 ATR 相对偏低；
- 因此 `sqrt(4)` 只能作为 sanity reference，不能作为交易阈值；
- 分布紧凑（IQR ≈ 0.16），但右偏且有右尾（max 2.83），意味着“比值异常升高”比“异常降低”更常见；
- R_clock 的离散程度（std 0.34）远大于 R_bar（std 0.13），说明时钟对齐口径对短期波动更敏感；
- R_bar 与 R_clock 相关 0.63，有共同信息但不完全重叠，两个口径都应保留。

## 4. 同周期短长 ATR 比（S_H / S_L）四象限

`S_H = ATR_1h(14) / ATR_1h(50)`，`S_L = ATR_15m(56) / ATR_15m(200)`，以 1 为界构成四象限：

| state_S | 条件 | 占比 | count |
|---|---|---:|---:|
| co_compress | S_H ≤ 1, S_L ≤ 1 | **56.5%** | 7,121 |
| co_expand | S_H > 1, S_L > 1 | **29.1%** | 3,669 |
| H_only | S_H > 1, S_L ≤ 1 | 9.7% | 1,221 |
| L_only | S_H ≤ 1, S_L > 1 | 4.8% | 599 |

### 4.1 关键观察

- **超过一半时间双周期都在压缩**，与 ATR squeeze 文献“市场大部分时间处于波动收缩”一致；
- 共振压缩 + 共振扩张合计约 **85.6%**，说明高/低周期 ATR 绝大多数时间同向运动；
- 纯单周期扩张很罕见：H_only 10%、L_only 5%；
- 后续按 state_S 分层时，H_only 和 L_only 组样本量较小，需要在报告中明确标注置信度；
- L_only 比 H_only 更罕见，说明“低周期独扩而高周期仍压缩”是相对稀有的状态。

## 5. R_bar × state_S 二维分布

按 R_bar 三分位 × state_S：

| R_bar | H_only | L_only | co_compress | co_expand |
|---|---:|---:|---:|---:|
| low | 2.6% | **8.3%** | **76.5%** | 12.7% |
| mid | 9.6% | 4.8% | 59.6% | 25.9% |
| high | **16.8%** | 1.1% | 33.3% | **48.7%** |

### 5.1 关键观察

- R_bar 低时：77% 是双压缩，8% 是 L_only（低周期独扩），仅 3% 是 H_only；
- R_bar 高时：49% 是共振扩张，17% 是 H_only（高周期独扩），仅 1% 是 L_only；
- R_bar 的高/低**主要由高周期 S_H 驱动**，而不是低周期被动压缩；
- 这验证了因子设计的核心直觉：R_bar 不是一个无方向的“波动比”，它的变化主要来自高周期波动状态。

## 8. 整体印象

1. **R_bar 是一个右偏、紧凑、有品种结构差异的比率**，中枢约 1.8，不是理论值 2.0；
2. **R_bar 的高低主要由高周期 ATR 驱动**，不是低周期被动压缩造成的——这与因子设计初衷一致；
3. **双周期共振是常态**（压缩 56% + 扩张 29% = 86%），纯单周期状态罕见；
4. **S_H 是与 R_bar 相关性最高的非平凡因子**（0.57），验证了同周期短长比作为主导周期识别因子的合理性；
5. **R_bar 与 R_clock 相关 0.63**，有共同信息但不完全重叠，两个口径都应保留；
6. **品种差异显著**：能化/有色 R_bar 约 1.9，农产品/黑色约 1.7，禁止跨合约池化阈值；
7. **H_norm 与 L_norm 高度共线**，后续只用 common_vol；
8. **20 根累计变化在高/低周期高度同步**（0.92），5 根窗口更有区分度，后续短期驱动分析优先用 5 根。

## 9. state_S 四象限的未来价格路径预测逻辑

> 本节是基于已有波动率微观结构文献和 EDA 观察得出的**假设**，不是已验证结论。Stage 3 将用未来收益和波动路径逐一检验。

四象限的预测逻辑建立在两个已有共识上：

1. **波动压缩—扩张循环**：低 ATR 状态后更容易出现大波动（同周期 ATR squeeze 文献的主要结论）；
2. **高周期承载主要方向信息**：高周期 ATR 扩张意味着更大级别的趋势/冲击正在释放，低周期 ATR 扩张多为盘中噪声。

### 9.1 co_compress（双压缩，56.5%）

**状态定义**：`S_H ≤ 1, S_L ≤ 1`，两个周期短窗 ATR 都低于长窗。

**微观解释**：市场全周期波动率枯竭，流动性收紧、买卖价差收敛，参与者在等待方向。这是 ATR squeeze 文献最关注的状态。

**未来路径假设**：

- **波动率**：未来 5–20 根 1h 内 ATR 扩张概率显著高于无条件基准；压缩越深、持续越久，后续扩张幅度越大；
- **方向**：本身不预测方向，需要额外的价格触发（突破、关键价位、外部事件）；
- **收益幅度**：|r_future| 应高于其他三象限，但 sign(r_future) 不确定；
- **R_bar 演化**：压缩阶段 R_bar 多在中低分位，扩张启动时若高周期先扩张，R_bar 快速上升；若低周期先扩张，R_bar 暂时下降后再上升；
- **关键分歧**：扩张后是真趋势还是假突破，取决于高周期 S_H 是否同步抬升。只有低周期先动而 S_H 保持 ≤1，更可能是噪声；S_H 跟上才是趋势启动。

**适用策略原型**：不直接交易方向，作为“波动扩张前夜”的预警状态，配合价格突破和成交量确认入场。

### 9.2 co_expand（共振扩张，29.1%）

**状态定义**：`S_H > 1, S_L > 1`，两个周期短窗 ATR 都高于长窗。

**微观解释**：全周期波动率同步放大，市场正在释放方向性运动。这通常对应已确认的趋势段或重大事件冲击。

**未来路径假设**：

- **波动率**：短期（5 根 1h）仍可能维持高位，但中长期（20–100 根）更可能向均值回归；
- **方向**：若进入该状态前已有明确趋势（高 MADEV / 动量强），趋势延续概率较高；若发生在大幅反转后，则更可能是冲击释放后的双向波动；
- **收益幅度**：|r_future| 在短期内仍大，但方向取决于进入状态前的趋势位置；
- **R_bar 演化**：
  - 若 `S_diff > 0`（高周期扩张更猛），R_bar 继续上升，趋势仍在加速；
  - 若 `S_diff ≈ 0`，双周期同步，趋势已进入中段；
  - 若 `S_diff < 0`（低周期扩张更猛），可能是趋势末端的盘中恐慌/过度交易；
- **衰竭信号**：D 组（累计变化）仍高但 E 组（变化速度）转负，是扩张见顶的候选信号。

**适用策略原型**：趋势跟随，但需要用 S_diff 和 E 组速度因子判断处于趋势早/中/末段，避免在末端追入。

### 9.3 H_only（高周期独扩，9.7%）

**状态定义**：`S_H > 1, S_L ≤ 1`，高周期短窗 ATR 扩张，低周期仍在压缩。

**微观解释**：更大级别的波动正在释放，但盘中短周期尚未跟进。这可能是：

- 高周期信息（宏观、政策、隔夜跳空）刚被定价，短周期还在消化；
- 或者高周期出现瞬时冲击但短周期不认可（假信号）。

**未来路径假设**：

- **波动率**：这是最不对称的状态。若高周期扩张是真实的，S_L 应在未来 1–5 根 1h 内跟上，进入 co_expand；若 S_L 持续不跟，S_H 会回落，回到 co_compress；
- **方向**：比 co_compress 更有方向含义——高周期扩张通常伴随价格突破关键位；
- **收益路径**：
  - 若 S_L 在 3–5 根内抬升 → 确认趋势启动，未来 20 根收益延续方向；
  - 若 S_L 不抬升 → 高周期扩张衰竭，未来 20 根可能反转或回到震荡；
- **R_bar**：进入该状态时 R_bar 多在高分位（二维表显示高 R_bar 组 H_only 占 17%）；若 R_bar 持续走高且 S_L 开始抬升，是最理想的趋势启动信号；
- **关键观察**：`dLogL_5` 是否在 3–5 根内由负转正。

**适用策略原型**：这是最值得关注的状态——既不像 co_compress 那样需要等待触发，也不像 co_expand 那样可能已在中段。H_only 可能提供“趋势刚启动但短周期尚未确认”的早期入场窗口，但必须设置 S_L 不跟进的止损。

### 9.4 L_only（低周期独扩，4.8%）

**状态定义**：`S_H ≤ 1, S_L > 1`，低周期短窗 ATR 扩张，高周期仍在压缩。

**微观解释**：盘中短周期波动放大，但更大级别没有认可。这通常是：

- 盘中噪声、算法交易、短期事件（如数据公布的瞬时反应）；
- 或者高周期正在蓄力但尚未突破，低周期先行“试探”。

**未来路径假设**：

- **波动率**：低周期扩张大概率衰减。S_L 已在高位而 S_H 不跟进，均值回归压力较大；
- **方向**：方向预测力最弱。低周期扩张产生的价格运动更可能是噪声而非趋势；
- **收益路径**：
  - 未来 5–20 根绝对收益可能偏高，但方向随机；
  - 若该状态出现在长期压缩（co_compress 持续很久）之后，可能是扩张的前兆——需要观察 S_H 是否在 5–10 根内跟上；
  - 若出现在 co_expand 之后，则更可能是趋势末端的残余波动；
- **R_bar**：进入该状态时 R_bar 多在低分位（二维表显示低 R_bar 组 L_only 占 8%）；
- **关键观察**：持续时间。L_only 超过 5 根 1h 仍不升级为 co_expand，衰减概率很高。

**适用策略原型**：不作为方向性入场信号。可作为“高周期仍压缩、短周期波动暂时放大”的过滤条件——例如在该状态下避免追涨杀跌，或作为 co_compress 向 co_expand 转换的早期预警。

### 9.5 状态转换假设

四象限不是静态标签，预期的典型转换路径：

```text
co_compress ──→ H_only ──→ co_expand ──→ co_compress
     │              ↑           │
     └──→ L_only ──┘           └──→ L_only ──→ co_compress
```

- **健康趋势路径**：co_compress → H_only → co_expand → co_compress；
- **噪声路径**：co_compress → L_only → co_compress（低周期先动但高周期不跟）；
- **衰竭路径**：co_expand → L_only → co_compress（高周期先冷却，低周期残余波动）；
- **最有价值的转换**：H_only 出现后 3–5 根内 S_L 抬升、进入 co_expand。

Stage 3 将统计实际的状态转移矩阵，并检验各象限的未来收益/波动路径是否符合上述假设。

### 9.6 与 R_bar 的联合使用

state_S 回答“谁在扩张”，R_bar 回答“高周期 ATR 相对低周期有多大”。两者联合：

| R_bar | state_S | 预期路径 |
|---|---|---|
| 高 | H_only | 高周期独扩 + 比值高 → 最可能是趋势早期，观察 S_L 是否跟进 |
| 高 | co_expand | 双扩 + 比值高 → 趋势可能已在中段，用 S_diff 判断是否到末段 |
| 高 | co_compress | 罕见（二维表仅 33%），可能是低周期压得更狠导致比值被动升高 |
| 低 | L_only | 低周期独扩 + 比值低 → 噪声概率高，方向预测力弱 |
| 低 | co_compress | 双压缩 + 比值低 → 典型 squeeze，等待方向触发 |
| 低 | co_expand | 双扩但比值低 → 低周期扩张更猛，可能是趋势末端或事件冲击 |
